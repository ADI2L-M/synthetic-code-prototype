Task 1 - Conditional Logic

PROGRAMMING TASK

Write a function that accepts a score and returns the corresponding grade classification.

FUNCTIONAL REQUIREMENTS

- Accept one numerical score.
- Return 'A' for scores from 80 to 100, 'B' for 60 to 79, 'C' for 50 to 59, and 'F' below 50.
- Reject scores outside the range 0 to 100 with a ValueError.

Task 2 - List Processing

PROGRAMMING TASK

Write a Python function named total_scores(scores) that calculates and returns the total of all integer values contained in a list.

FUNCTIONAL REQUIREMENTS

- The function must be named total_scores.
- The function must accept one parameter named scores.
- The parameter scores will be a list containing zero or more integers.
- The function must calculate the total of all values in scores.
- If scores is empty, the function must return 0.
- The function must not use Python's built-in sum() function.
- The function must return the calculated total as an integer.
- The function must not print the result.

PROGRAMMING TASK

Write a Python function named sum_to_n(n) that calculates and returns the sum of all integers from 1 through n, inclusive.

FUNCTIONAL REQUIREMENTS

- The function must be named sum_to_n.
- The function must accept one parameter named n.
- The input n will always be a positive integer greater than or equal to 1.
- The function must calculate the sum of all integers from 1 through n.
- The calculation must use iteration.
- The function must not use Python's built-in sum() function.
- The function must not use a direct mathematical summation formula.
- The function must return the calculated total as an integer.
- The function must not print the result.
